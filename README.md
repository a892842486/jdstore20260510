# JDStore

Rails 8 電商網站作品，
支援商品瀏覽、購物車、訂單流程、
AASM 訂單狀態管理與中英文切換。

---

## Live Demo

網站：
https://jdstore20260510.onrender.com

GitHub：
https://github.com/a892842486/jdstore20260510

---

## Features

### 使用者功能
- 商品瀏覽
- 購物車
- 結帳流程
- 多語系切換（中文 / English）

### 管理功能
- 商品 CRUD
- 圖片上傳
- 訂單管理
- AASM 訂單狀態流轉

---

## Tech Stack

- Ruby on Rails 8
- PostgreSQL
- Tailwind CSS
- Devise
- AASM
- AWS S3
- Render

## Features

### 使用者功能
- 商品瀏覽
- 購物車
- 結帳流程
- 多語系切換（中文 / English）

### 管理功能
- 商品 CRUD
- 圖片上傳
- 訂單管理
- AASM 訂單狀態流轉

---

## Tech Stack

- Ruby on Rails 8
- PostgreSQL
- Tailwind CSS
- Devise
- AASM
- AWS S3
- Render
